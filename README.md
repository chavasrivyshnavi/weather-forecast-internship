# 🌦️ Weather Forecast Application

A responsive weather forecast application built using React.js and the OpenWeather API.

## 🚀 Features

- Current weather information
- Weather forecast
- City-based weather search
- Location-based weather information
- Light and dark theme
- Responsive design
- Dynamic weather backgrounds
- API integration
- Loading and error handling

## 🛠️ Technologies Used

- React.js
- JavaScript
- HTML5
- CSS / SCSS
- Tailwind CSS
- OpenWeather API
- Node.js
- Vercel Serverless Functions
